# EW200: Intro to Programming and Design

August 2023 - December 2023

**[GitHub Repository](https://github.com/bandofpv/EW200)**

## Course Description

This was my first robotics course at USNA.

<details>

<summary>Course Catalog Description</summary>

This course acts as an introduction to the robotics and control engineering major, focusing on programming, and the development of hardware and software solutions to engineering problems. Using a project-based approach, the course ties together topics from the core, introduces the basics of technical communication and the design process.

</details>

<details>

<summary>Learning Outcomes</summary>

- [x] To understand the basic tools and techniques of Robotics & Control engineering
- [x] To design algorithms to solve a variety of problems
- [x] To demonstrate a proficiency with:
  - [x] Python programming language
  - [x] Circuit Python for micro controllers
- [x] To demonstrate a familiarity with:
  - [x] Object Oriented Programming
  - [x] Hardware prototyping
  - [x] Open Source software libraries
- [x] To provide insight into the engineering process

</details>
